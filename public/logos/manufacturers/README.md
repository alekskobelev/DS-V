# Папка подписанных логотипов компаний-производителей («ДС-Инжиниринг»)

В эту папку помещаются официальные логотипы компаний-производителей метрологического оборудования и ПО для автоматического использования:
1. В бланках свидетельств об обучении (левый и правый партнерские логотипы).
2. В разделах сайта (партнеры, поставщики, бренды каталога КИМ и 3D-сканеров).
3. В печатных формах коммерческих предложений и сервисных актов.

---

## Рекомендации по формату файлов:
- **Векторный формат (рекомендуется):** `.svg` (обеспечивает идеальную четкость при печати A4 в любом масштабе).
- **Растровый формат:** `.png` с **прозрачным фоном** (Alpha-channel), разрешение по высоте не менее 120-200 px (300 DPI для полиграфической печати).
- **Цветовая палитра:** Оригинальные фирменные цвета бренда или монохромный/темный вариант для белого листа бланка.

---
