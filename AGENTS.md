# ИНСТРУКЦИИ ДЛЯ АГЕНТА РАЗРАБОТКИ (AGENTS.MD)

## ОБЯЗАТЕЛЬНОЕ ПРАВИЛО ВЕДЕНИЯ ДОКУМЕНТАЦИИ:
При выполнении ЛЮБЫХ правок, доработок кода, добавлении функционала или изменении структуры сайта **ОБЯЗАТЕЛЬНО** актуализировать соответствующие документы:

1. **`docs/SITE_PASSPORT.md`** (Паспорт сайта) — обновлять версию, дату, архитектуру, стек технологий, список модулей или контактные данные при их изменении.
2. **`docs/USER_MANUAL.md`** (Инструкция по эксплуатации) — обновлять шаги работы с CMS, описание новых элементов управления, форм, настроек калькулятора, каталога и CRM.
3. **`docs/CHANGELOG.md`** (История изменений) — вносить новую запись о внесенных правках в хронологическом порядке с описанием добавленных возможностей, улучшений и исправлений.
4. **`docs/DATABASE_DEPLOYMENT.md`** (Развертывание БД) — актуализировать инструкции по СУБД, переменным окружения, миграциям схемы Drizzle ORM.
5. **`docs/README.md`** (Реестр документации) — поддерживать актуальный список документов и порядок быстрого старта.
6. **`README.md`** в корне — актуализировать описание системы, стек, модули и порядок запуска.

---

## СТЕК И ПРАВИЛА КОДА:
- **Фронтенд:** React 18 + TypeScript + Vite + Tailwind CSS + Lucide Icons + Three.js (3D WebGL просмотрщик моделей и карт отклонений GD&T).
- **Бэкенд:** Node.js (Express) + REST API + WebSocket/Live API.
- **База данных:** **PostgreSQL 17** (образ `postgres:17-alpine`, Drizzle ORM, пул `pg`) + гибридный отказоустойчивый fallback (in-memory + дисковая персистентность в `data/`).
- **Порт сервера:** строго 3000 (0.0.0.0:3000).
- Все иконки импортируются исключительно из `lucide-react`.
- Все тексты, интерфейсы и документация ведутся на русском языке с сохранением профессионального инженерно-промышленного тона («ДС-Инжиниринг»).

## ОБЯЗАТЕЛЬНОЕ ПРАВИЛО ЧИСТОТЫ КОРНЕВОЙ ДИРЕКТОРИИ (ROOT CLEANLINESS):
- В корне проекта разрешено хранить **ТОЛЬКО самые необходимые конфигурационные и входные файлы**:
  - `package.json`, `package-lock.json`
  - `tsconfig.json`, `vite.config.ts`
  - `server.ts`
  - `index.html`, `metadata.json`
  - `.env.example`, `.gitignore`
  - `README.md`, `AGENTS.md`
  - `docker-compose.yml`, `firebase-applet-config.json`
- **СТРОГО ЗАПРЕЩЕНО** оставлять в корне проекта временные патч-скрипты (`*.cjs`, `*.js`, `*.py`, `*.sh`, `*.patch`), дампы, тестовые утилиты или побочные lock-файлы.
- Все вспомогательные скрипты обслуживания и миграций должны переноситься в директорию `scripts/` (или удаляться, если они больше не нужны), документация — строго в `docs/`, данные — в `data/`.
