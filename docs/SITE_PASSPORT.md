### 1. ОБЩИЕ СВЕДЕНИЯ О РЕСУРСЕ
* **Полное наименование:** Официальный корпоративно-инжиниринговый портал компании «ДС-Инжиниринг» (DS Engineering).
* **Сфера деятельности:** Поставка, внедрение и сопровождение CAD/CAM/CAE/PDM систем (Geomagic, Shining 3D EXModel/Inspect), метрологического оборудования (КИМ PMT, Hexagon, оптические 3D-сканеры Shining 3D / FreeScan, лазерные трекеры Leica), оказание услуг 3D-сканирования, контроля геометрии и реверс-инжиниринга.
* **Целевая аудитория:** Главные инженеры, главные технологи, метрологи, руководители инструментальных и механических производств, конструкторские бюро предприятий ВПК, авиакосмической, автомобильной и тяжелой промышленности.
* **Язык интерфейса:** Русский (с поддержкой локализации).

### 3. СТРУКТУРА И ФУНКЦИОНАЛЬНЫЕ МОДУЛИ

1. **Главный портал (Интерактивная витрина и слайдер):**
   * Интерактивный 6-позиционный мультимедийный слайдер (`HeroSlider`) с презентацией ключевых направлений (КИМ и 3D-метрология, CAD/CAM/PDM TopSolid 7, метрология PolyWorks|Inspector, реверс-инжиниринг Geomagic Design X / Control X, САПР Shining 3D EXModel Pro & Inspect, выездные инженерные услуги по РФ).
   * Выверенная типографика и пропорциональные информационные карточки с техническими спецификациями.
   * Быстрый интерактивный блок подбора решений под отраслевые задачи.
   * Каталог флагманских продуктов (TopSolid 7, PolyWorks, PMT Alpha, Hexagon Absolute Arm, FreeScan Combo).
   * Блок доверия: реализованные проекты, клиенты, сертификаты, более 30 лет опыта.

2. **Каталог программного обеспечения (CAD/CAM/PDM, 3D-Метрология, Реверс-инжиниринг):**
   * **3 инженерных вектора:**
     1. CAD/CAM/PDM (TopSolid 7: Design, Cam, Mold, Progress, Wire, Wood, Sheetmetal, PDM);
     2. 3D-Метрология и контроль качества (PolyWorks|Inspector, Modeler, Geomagic Control X, SHINING 3D Inspect с сертификатом PTB Class 1);
     3. Реверс-инжиниринг и обратное проектирование (Geomagic Design X, Shining 3D EXModel / EXModel Pro).
   * **Матрица отраслевого применения:** наглядное сопоставление технологических задач предприятия с оптимальными программными комплексами.
   * **Архитектура подпредставлений (True Sub-Routing):** независимые модули `/software/topsolid`, `/software/polyworks`, `/software/geomagic`, `/software/shining3d-sw` с собственным Scrollspy.
   * Интерактивная база инженерных FAQ для каждого программного продукта с поиском, фильтрацией по тегам и копированием ответов.
   * Выгрузка коммерческих предложений, брошюр и заказ демонстраций на данных заказчика.

3. **Каталог метрологического оборудования:**
   * Стационарные портальные КИМ (Mitutoyo CRYSTA-Apex S, PMT CMM).
   * Портативные измерительные руки и лазерные 3D-сканеры (Hexagon Absolute Arm, FreeScan Combo, PMT Alpha Arm, TrackScan).
   * **Строгая фасетная фильтрация (`HardwareFacetFilter` + `hardwareMetrology.ts`):**
     * Блок *«Точность (погрешность)»*: Сверхточные (до 0,01 мм), Высокоточные (0,01 мм — 0,05 мм), Базовые (от 0,05 мм и выше) с динамическими счетчиками приборов.
     * Блок *«Форм-фактор»*: Стационарные и Портативные.
     * Блок *«Метрологический статус»*: приборы из Госреестра СИ РФ (ФГИС «АРШИН»).
     * Синхронизация с поисковой строкой, брендовым селектором и категориями оборудования, строка активных фасет-бейджей и сброс фильтров.
   * **Интерактивная метрологическая диаграмма сравнения (`HardwareComparisonChart` на базе Recharts):**
     * Лепестковая диаграмма (RadarChart) — 5-факторный «Метрологический профиль» (Прецизионность MPE, Скорость сбора данных, Детализация рельефа, Охват зоны, Цеховая мобильность) по 100-балльной нормированной шкале ISO 10360;
     * Столбчатая гистограмма (BarChart) — детальное сопоставление физических величин: погрешность (мкм), скорость сканирования (тыс. тчк/с), шаг сетки (мкм), рабочий диапазон (мм), масса (кг);
     * Экспертный метрологический вердикт «ДС-Инжиниринг» с автоопределением эталона точности, лидера производительности и статуса во ФГИС «АРШИН»;
     * Интеграция в модуль сравнения `CompareDrawer` с тумблером быстрого скрытия и добавлением моделей из графика.
   * Сравнительная таблица технических характеристик и погрешностей (MPEe).
   * **Техническая документация:** специальный блок со списком доступных для скачивания файлов (Описания типа СИ, сертификаты, руководства).

4. **Инжиниринговые услуги и интерактивный калькулятор:**
   * 3D-сканирование на выезде и в лаборатории.
   * Контроль геометрии и отклонений от CAD-модели (Color Map).
   * Реверсивный инжиниринг деталей со сложными поверхностями.

### 4. ТРЕБОВАНИЯ К ХОСТИНГУ И СЕРВЕРНОМУ ОКРУЖЕНИЮ
* **Архитектура развертывания:** VPS / VDS сервер (рекомендуется Ubuntu 22.04/24.04). Обычный виртуальный хостинг (Shared Hosting) не поддерживается.
* **Контейнеризация:** Docker + Docker Compose (обязательно для запуска).
* **Сетевое хранилище (NAS):** Для хранения тяжелых файлов (CAD-модели до 10 ГБ) используется корпоративный NAS (ASUSTOR / TrueNAS Scale) в связке с протоколом S3 (MinIO) через FastAPI Backend.
* **Node.js:** версия 18.x или 20.x LTS.
* **База данных:** PostgreSQL 17 (образ `postgres:17-alpine` в Docker Compose) + Drizzle ORM.
* **Порт приложения:** 3000 (0.0.0.0:3000).
* **Сетевой стек:** Nginx Reverse Proxy / Cloud Run Container.
* **HTTPS/SSL/TLS:** Обязателен для промышленной эксплуатации. Поддерживается коммерческий TLS/SSL-сертификат от REG.RU (файлы `fullchain.crt` и `private.key` в директории `nginx/ssl/`), современные протоколы TLS 1.2 / TLS 1.3, HTTP/2, безопасные шифры и автоматический 301-редирект с HTTP (порт 80) на HTTPS (порт 443).
