## 💾 2. Структура базы данных и гибридное хранилище

### 2.1. Реляционные таблицы PostgreSQL 17 (`src/db/schema.ts`):
1. **`users`** — системные пользователи и сотрудники (роли: `superadmin`, `admin`, `manager`, `engineer`, `client`, `guest`, права доступа RBAC).
2. **`text_constants`** — глобальные текстовые константы интерфейса сайта (`key`, `value`, `category`, `updated_at`).
3. **`cms_pages`** — кастомные страницы конструктора CMS (`slug`, `title`, `blocks`, `seo`).
4. **`equipment`** — номенклатура измерительных машин, 3D-сканеров, трекеров и щупов.
5. **`services`** — каталог инжиниринговых услуг (3D-сканирование, контроль геометрии, реверс, постпроцессоры, оснастка).
6. **`crm_companies`** — предприятия-контрагенты РФ с автопоиском по ИНН через DaData.
7. **`crm_contacts`** — ключевые лица (ЛПР, главные метрологи, начальники ОТК, главные технологи).
8. **`crm_deals`** — сделки в 3 воронках продаж (Оборудование, Услуги, Сервис) с расчетом НДС 22%.
9. **`crm_tasks`** — задачи сервисных инженеров и менеджеров с дедлайнами и чек-листами.
10. **`crm_proposals`** — реестр коммерческих предложений (ТКП) с генерацией PDF.
11. **`crm_contracts`** — договоры поставки оборудования и оказания услуг с графиком платежей.
12. **`crm_licenses`** — учет лицензий ПО TopSolid 7, PolyWorks, Geomagic и ключей защиты.
13. **`tickets`** — обращения в техническую поддержку B2B Service Desk.
14. **`service_requests`** — входящие заявки с калькуляторов, онлайн-инженера и форм сайта.

### 2.2. Механизм мгновенного Fallback:
При отсутствии подключения к PostgreSQL 17 (например, в изолированных контейнерах или при перезапуске СУБД) шлюз `server.ts` автоматически переходит на гибридный режим:
- Считывание и сохранение данных в файлы `data/*.json` (`data/cms_store.json`, `data/notificationSettings.json`, `data/models3d.json`, `data/priceLists.json`);
- Запросы API возвращают статус 200 OK с заголовками целостности;
- Ни один лид, расчет или заявка не теряется.

## 🤖 3. Мульти-шлюз оповещений инженеров (МАКС / Telegram / Email)

Шлюз `src/server/notificationModule.ts` обеспечивает гарантированную параллельную доставку всех обращений:

1. **Российский корпоративный мессенджер МАКС:**
   - Переменные: `MAX_BOT_TOKEN`, `MAX_CHAT_ID`, `MAX_WEBHOOK_URL`, `MAX_API_URL`.
   - Защищенный корпоративный канал для закрытых производственных сетей.
2. **Telegram Bot API:**
   - Переменные: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
   - Мгновенные мобильные пуш-уведомления дежурной смене.
3. **Корпоративная SMTP-почта (`src/server/emailModule.ts`):**
   - Переменные: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `ALERT_EMAIL_RECIPIENTS`.
   - Фирменные HTML-бланки с реквизитами заявки и прямыми ссылками в CRM.
4. **Звуковые и всплывающие оповещения (CRM Real-Time):**
   - Звуковой сигнал Web Audio API и всплывающие карточки на экранах операторов.

- `npm run test:e2e` — запуск сквозных UI и API тестов Cypress в headless-режиме;
- `npm run lint` — проверка строгой типизации TypeScript (`tsc --noEmit`);
