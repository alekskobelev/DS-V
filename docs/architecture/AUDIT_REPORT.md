# КОМПЛЕКСНЫЙ ИНЖЕНЕРНО-ТЕХНИЧЕСКИЙ И ГРАФИЧЕСКИЙ АУДИТ ВЕБ-ПОРТАЛА
## Цифровая платформа и CRM-система ООО «ДС-Инжиниринг»

**Дата проведения аудита:** 20 октября 2026 г.  
**Версия системы:** v2.9.283-PROD  
**Статус ресурса:** Эксплуатация / Production  
**Объект аудита:** Корпоративный портал (6 модернизированных экранов главной страницы), каталог оборудования и ПО, калькуляторы, 3D WebGL просмотрщик, B2B CRM, CMS-панель и Личный кабинет заказчика.

---

# ЧАСТЬ 1. ТЕХНИЧЕСКИЙ И СИСТЕМНЫЙ АУДИТ ПОРТАЛА

### 1. Архитектура и технологический стек
* **Фронтенд:** React 18 (TypeScript), Vite, Tailwind CSS v4, Lucide Icons, Three.js WebGL (3D-визуализация CAD и GD&T), Recharts.
* **Бэкенд:** Node.js, Express REST API, WebSocket/Live API.
* **База данных:** PostgreSQL 17 (`postgres:17-alpine`, Drizzle ORM, пул `pg`) + локальная дисковая персистентность (`data/`) при аварийных сбоях сети. *Redis в системе отсутствует и не используется (кэширование сессий организовано в памяти процесса Node.js с нулевыми задержками).*
* **Организационная структура в интерфейсе:** Компактный формат команды практиков (до 10 сотрудников), прямой контакт заказчика с ведущими инженерами, полное исключение бюрократических клише и вымышленных «отделов».
* **Производственные локации:** Центральный офис и инженерная база в Самаре (ул. Свободы, д. 198) и демонстрационно-метрологический зал в Тольятти (Технопарк «Жигулевская долина», Южное шоссе, 165, корп. 2.3 и корп. 3.2 с КИМ Mitutoyo CRYSTA-Apex S) + выездные мобильные группы по всей РФ (норматив 24–48 ч).
* **Внешние интеграции:** DaData API (верификация контрагентов РФ по ИНН/ЕГРЮЛ без синтетических данных), Яндекс.Метрика (счетчик № 112028524), Яндекс 360 SMTP, Российский мессенджер МАКС, Telegram Bot API.

### 2. Функциональная полнота модулей
1. **Каталог ПО и матрица применения:**
   * Полные отраслевые разделы TopSolid 7 (Design, Cam, Mold, Progress, Wood), PolyWorks (Inspector, Modeler, ретрофит КИМ), Geomagic (Design X, Control X), Shining 3D Inspect;
   * Интерактивная таблица совместимости систем ЧПУ (Fanuc, Siemens Sinumerik, Heidenhain, Балт-Систем, Маяк).
2. **Каталог оборудования и метрологический контроль:**
   * Стационарная КИМ Mitutoyo CRYSTA-Apex S (метрологический зал в технопарке «Жигулевская долина»), портативные КИМ PMT Alpha Arm, оптико-лазерные 3D-сканеры Shining 3D FreeScan Combo и ScanLine EasyScan Omni;
   * 4-шаговый конфигуратор подбора СИ с расчетом запаса точности ($T/\text{MPE} \ge 3.0$) и B2B ROI калькулятор окупаемости внедрения;
   * Фильтрация приборов по статусу в Госреестре СИ (ФГИС «АРШИН»).
3. **Инжиниринговые услуги:**
   * 7 сквозных услуг полного цикла (3D-сканирование, контроль геометрии/GD&T, поставка и ПНР, разработка постпроцессоров, реверс в STEP по ЕСКД, проектирование пресс-форм/штампов, сервис и калибровка КИМ);
   * Комплексная валидация входных данных (`validateServiceItem`, `validateEquipmentArray`, `validateContactLink`).
4. **Инженерная CRM и Личный кабинет заказчика:**
   * Канбан-воронки (Оборудование, Услуги, Сервис), генератор ТКП/АКП в PDF с факсимиле и печатями, реестр средств измерений (Fleet), реестр метрологических отчетов, конструктор свидетельств операторов КИМ.

### 3. Информационная безопасность и нормативное соответствие РФ
* **152-ФЗ («О персональных данных»):** чекбоксы согласия во всех формах, изолированное хранение персональных данных.
* **242-ФЗ (Локализация баз данных):** PostgreSQL 17 развернута на территории РФ.
* **Защита от CSRF/XSRF:** криптографический Synchronizer Token Pattern (64-char hex) с валидацией всех модифицирующих запросов (POST, PUT, DELETE).
* **Валидация API (Draft-07):** 13 строгих спецификаций JSON Schema (Ajv v8) с русскоязычной локализацией ошибок.
* **Ролевая модель доступа (RBAC):** 6 уровней доступа (Superadmin, Admin, Moderator, Manager, Engineer, Client).

# ЧАСТЬ 2. ГРАФИЧЕСКИЙ, ВИЗУАЛЬНЫЙ И UI/UX АУДИТ

### 1. Соответствие дизайн-конституции (Design Constitution & Anti-Slop)
* **Цветовая палитра:**
  - *Основной корпоративный цвет:* Инженерный синий/нави `#1E3A8A` (глубокий, строгий, промышленный);
  - *Фоновые поверхности:* Светлая тема `#F3F4F6` / `#FFFFFF`; Темная тема `#0B0F17` / `#111827` (без дешевых фиолетовых градиентов);
  - *Акцентный цвет:* Янтарный `#F59E0B` / `#D97706` для фокусных кнопок и статусов.
* **Двухрежимная тема (Light / Dark Mode):**
  - Поддержка системных настроек ОС и ручной тумблер с сохранением в `localStorage`;
  - Коэффициент контрастности текста WCAG AA $\ge 4.5:1$ на всех поверхностях.
* **Zero-Pill & Metadata Discipline:**
  - Отсутствие статических цветных "пилюль" и дешевых капсул на информационных метках;
  - Метаданные (категории, даты, ГОСТы, приборы) оформлены чистым текстом с точечными разделителями (`·`);
  - Интерактивные переключатели (фильтры, табы, сегментированные кнопки) имеют четкое разделение состояний `active / hover`.

### 2. Типографика и числовой дизайн (Data Density)
* Строгая иерархия шрифтов: `font-sans` для интерфейса, `font-mono` с `tabular-nums` для технических таблиц, координат, погрешностей в микронах (мкм) и денежных сумм;
* Пропорциональные отступы: внешние отступы контейнеров $\ge$ внутренних отступов элементов.

### 3. Интерактивная 3D-графика (Three.js WebGL & GD&T)
* Полноценный аппаратный 3D-просмотрщик моделей (`CadModel3DViewer.tsx`):
  - Центральный триэдр системы координат (X/Y/Z) на базовой плоскости детали;
  - Полярная сетка координатной привязки;
  - Динамические выносные флажки замеров с кривыми Безье (SVG Leader Lines);
  - Цветовая шкала отклонений GD&T (в стиле Geomagic Control X / PolyWorks|Inspector);
  - Защита интеллектуальной собственности: запрет прямого скачивания CAD-файлов неавторизованными пользователями и наложение защитного водяного знака.

### 4. Адаптивность и мобильный UX
* Контейнер быстрых действий (`BottomNavigationActions` / `#mobile-bottom-nav-actions`):
  - Фиксирован внизу экрана (`fixed bottom-0 inset-x-0`) с учетом `safe-area-inset-bottom`;
  - Кнопка онлайн-консультанта (`ChatWidget`) и заказа звонка (`CallbackFloatingButton`) размещены гармонично и не перекрывают центр экрана;
  - Кнопка «Наверх» аккуратно интегрирована в правый угол;
  - Исключен горизонтальный скролл страницы (`overflow-x: clip`).
