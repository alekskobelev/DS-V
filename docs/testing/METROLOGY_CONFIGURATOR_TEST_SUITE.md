## 📝 Детальное описание ключевых тест-кейсов

### Тест-кейс TC-MET-01: Динамическое масштабирование и 3D-визуализация заготовки
- **Предусловия:** Открыто модальное окно «Метрологический конфигуратор оборудования СИ».
- **Шаги:**
  1. На шаге 1 переместить слайдер длины $X$ со 100 мм до 800 мм.
  2. Переместить слайдер ширины $Y$ со 100 мм до 600 мм.
  3. Переместить слайдер высоты $Z$ со 100 мм до 450 мм.
  4. Установить массу детали 85 кг.
- **Ожидаемый результат:**
  - На 3D-сцене Three.js габаритная сетка и твердотельная CAD-модель плавно масштабируются по 3 осям с сохранением пропорций.
  - В информационной панели пересчитывается объем заготовки: $V = 800 \times 600 \times 450 \text{ мм}^3 = 216.0 \text{ л (дм}^3\text{)}$.
  - Рассчитывается удельная плотность материала $\rho = 85 / 216 \approx 0.39 \text{ кг/дм}^3$.
  - Отсутствуют ошибки WebGL в консоли браузера.

### Тест-кейс TC-MET-05: Валидация полей допусков по ГОСТ (квалитеты IT5–IT12)
- **Предусловия:** Выполнен переход на Шаг 2 («Допуски чертежа и точность GD&T»).
- **Шаги:**
  1. Выбрать квалитет точности **IT5** (Прецизионные подшипниковые шейки, расточки корпусов).
  2. Зафиксировать рассчитанное поле допуска $T_{\text{IT5}}$.
  3. Переключить квалитет на **IT7** (Фрезерованные посадочные плоскости).
  4. Переключить на **IT9** (Отверстия под крепеж, свободные размеры).
  5. Переключить на **IT12** (Литые и штампованные необработанные базы).
- **Ожидаемый результат:**
  - Значение поля допуска строго соответствует формуле ГОСТ: для IT5 $\approx 9$–$15$ мкм, для IT7 $\approx 25$–$40$ мкм, для IT9 $\approx 80$–$130$ мкм, для IT12 $\approx 250$–$400$ мкм в зависимости от габарита $L$.
  - При вводе пользовательского значения в поле «Точный допуск» активируется ручной режим с сохранением введенного числа.

### Тест-кейс TC-MET-08: Расчет метрологического запаса точности $T/\text{MPE}$
- **Предусловия:** Заданы габариты $500 \times 400 \times 300$ мм, квалитет IT7 ($T = 30$ мкм), среда ЦЗЛ ($20^\circ\text{C}$). Выполнен переход на Шаг 4.
- **Шаги:**
  1. Оценить формулу предельной погрешности рекомендованной портальной КИМ: $\text{MPE}_E = 1.8 + 3.0 \cdot L / 1000 = 1.8 + 1.5 = 3.3$ мкм.
  2. Вычислить коэффициент запаса точности:
     $$K_{\text{reserve}} = \frac{T}{\text{MPE}_E} = \frac{30}{3.3} \approx 9.09$$
  3. Проверить статус метрологического соответствия.
- **Ожидаемый результат:**
  - Отображается зеленый статус-бейдж **«Оптимальный запас точности (ГОСТ)»** ($K_{\text{reserve}} = 9.1 \ge 4.0$).
  - Выводится рекомендация: «Прибор гарантирует отсутствие ложного забракования годных деталей по ГОСТ ISO 14253-1».

### Тест-кейс TC-MET-12: Сквозная синхронизация настроек CMS с конфигуратором
- **Предусловия:** Авторизован пользователь с ролью `superadmin` / `admin`.
- **Шаги:**
  1. Перейти в CMS ➔ вкладка «Конфигураторы» (`CmsConfiguratorsTab.tsx`).
  2. Изменить длину заготовки по умолчанию с 450 мм на **620 мм**.
  3. Изменить часовую ставку инженера ОТК с 1200 руб/час на **1650 руб/час**.
  4. Нажать кнопку **«Сохранить настройки конфигураторов»**.
  5. Открыть публичный Метрологический конфигуратор оборудования СИ.
- **Ожидаемый результат:**
  - Запрос `POST /api/cms/store/configurators_settings` возвращает статус 200 OK.
  - При открытии конфигуратора слайдер длины автоматически инициализируется значением **620 мм**.
  - В B2B ROI калькуляторе базовая ставка ОТК автоматически установлена в **1650 руб/час**.
