## 🚀 Быстрый запуск проверок

```bash
# 1. Запуск всех регрессионных и интеграционных тестов (131 тест)
npm test

# 2. Запуск программного аудита Lighthouse & Core Web Vitals (FCP, LCP, a11y)
npm run audit:lighthouse

# 3. Запуск автоматизированного аудита SEO-метаданных и соцсетей (185 страниц)
npm run seo:audit

# 4. Запуск модульных тестов компонентов (Vitest)
npm run test:unit

# 5. Запуск сквозных E2E-тестов (Cypress)
npm run test:e2e

# 6. Полная проверка типизации TypeScript
npm run lint

# 7. Проверочная производственная сборка (Vite + esbuild)
npm run build
```
