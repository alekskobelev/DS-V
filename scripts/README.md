# Вспомогательные скрипты и патчи проекта (`/scripts/`)

В данной папке собраны утилитарные скрипты автоматизации, миграции и патчи, применяемые при обслуживании каталогов, навигации и структуры проекта **ООО «ДС-Инжиниринг»**.

---

## 🛠 Содержимое директории

| Категория | Файлы | Описание |
| :--- | :--- | :--- |
| **Скрипты миграции и категорий** | `fix_categories.py`, `fix_categories2.py`, `add_other_category.py`, `fix_counts.py` | Обработка и нормализация категорий каталогов оборудования и ПО. |
| **Скрипты фильтрации и логики** | `fix_brand_logic.py`, `fix_filter_logic.py`, `fix_search_view.py` | Корректировка алгоритмов фильтрации бренд-линков и поиска. |
| **Патчи и структуры компонентов** | `fix_card_structure.sh`, `fix_dropdowns.py`, `fix_mobile_menu.patch`, `replace_header.py` | Вспомогательные скрипты правки интерфейсных компонентов. |
| **Обновление документации** | `update_changelog.sh`, `update_changelog2.sh` | Утилиты автоматического внесения записей в журналы изменений. |

---

## ⚠️ Эксплуатация

Скрипты запускаются при необходимости технического обслуживания через Python или Bash:

```bash
python3 scripts/fix_categories.py
bash scripts/update_changelog.sh
```
