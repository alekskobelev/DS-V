# ООО «ДС-Инжиниринг» — Проектная и Эксплуатационная Документация

> 📁 **Вся проектная и эксплуатационная документация собрана в отдельной папке [`/docs/`](./docs/README.md).**

Цифровая платформа и инженерно-коммерческий портал компании **ООО «ДС-Инжиниринг»** (официальный интегратор CAD/CAM/PDM систем TopSolid 7 SAS, метрологического ПО PolyWorks|Inspector™, портативных оптических и синих лазерных 3D-сканеров Shining 3D FreeScan и ScanLine EasyScan Omni, мобильных КИМ PMT Alpha Arm и систем Renishaw). Включает оптимизированную рабочую среду B2B CRM с живым поиском любых контрагентов РФ по ИНН через DaData API (без генерации фиктивных организаций), модуль управления реальными инжиниринговыми услугами, измерительным оборудованием и контактами специалистов (`CmsServicesEditor.tsx` & `src/data/services.ts`) с комплексной системой валидации непустых полей, типов массивов оборудования (`Array<string>`) и URL-ссылок контактов, реестр коммерческих предложений (просмотр бланка в 1 клик по строке/карточке с прямым переходом к редактированию, компактный вид карточек, генерация КП с шаблонами White-label, вставка изображений и файлов, официальная подпись руководителя Некрасова С.Ю. и блок исполнителя), динамическую настройку ставок НДС, сквозной поиск (`GlobalSearch.tsx`), глобальный `ThemeContext` (Light/Dark), полиграфический конструктор ТКП и ТЗ (`TkpTzGeneratorView.tsx`), модуль корпоративной телефонии и SIP-звонков (`TelephonyCallsTab.tsx`), аппаратную отказоустойчивость 3D WebGL просмотрщика (`CadModel3DViewer.tsx`) и модуль рекомендательных прайс-листов.

## 1. Концепция и назначение портала

### 1.1. Основная цель проекта
> **Создать единую цифровую витрину и инженерный портал «ДС-Инжиниринг»**, объединяющий каталог прецизионного оборудования (измерительные руки Hexagon Absolute Arm, сканеры AS1, КИМ PMT, трекеры Leica), лицензионного программного обеспечения (TopSolid 7, PolyWorks), инженерные услуги (3D-сканирование, разработка постпроцессоров, модернизация КИМ), интерактивный расчет стоимости и закрытый личный кабинет заказчика для оперативного сопровождения.

### 1.2. Целевая аудитория и ключевые задачи

| Группа пользователей | Должность / Роль | Основная производственная задача | Сценарий работы на портале |
| :--- | :--- | :--- | :--- |
| **Главный технолог / Главный инженер** | Руководитель технической службы завода / КБ | Сокращение сроков запуска изделий на станках с ЧПУ, ликвидация брака, сквозное управление техпроцессами. | Изучение возможностей TopSolid 7, заказ демонстрации, оформление заявки на разработку постпроцессора. |
| **Главный метролог / Начальник ОТК** | Руководитель службы контроля качества | Высокоточный бесконтактный и контактный 3D-контроль деталей без матирующего спрея, переоснащение КИМ. | Подбор комплекса *Hexagon Absolute Arm + AS1 + PolyWorks*, оценка параметров точности, заказ выездных измерений. |
| **Специалист отдела снабжения / МТО** | Руководитель закупок / Тендерный специалист | Своевременное получение коммерческих предложений, подтверждение статуса официального дилера, прозрачные договоры. | Формирование спецификации, скачивание коммерческого предложения и реквизитов компании, запрос счета. |
| **Инженер / Оператор КИМ и ЧПУ** | Специалист на производстве | Оперативное решение технических вопросов, устранение сбоев, запрос драйверов и свидетельств о поверке. | Личный кабинет: оформление заявки в техническую поддержку, скачивание обновлений и постпроцессоров. |
| **Редактор портала / Маркетолог** | Администратор сайта | Актуализация каталога оборудования, публикация выполненных проектов и новостей без привлечения программистов. | Панель управления сайтом: редактирование разделов, каталога, прейскуранта и просмотр статистики обращений. |

### 1.3. Ключевые показатели эффективности
* **Число целевых коммерческих обращений:** рост объема подтвержденных заявок на поставку оборудования, лицензий и инжиниринговых услуг.
* **Конверсия посетителей в заявки:** доля пользователей, оформивших предварительный расчет или оставивших обращение, не менее $3.8\%$.
* **Скорость предварительного расчета:** сокращение времени получения первичной сметы на услуги сканирования и постпроцессоров до 60 секунд за счет интерактивного расчетного модуля.
* **Качество сервисного обслуживания:** удовлетворенность заказчиков скоростью решения технических вопросов через личный кабинет не менее $92\%$.

## 2. Организация гибкой разработки (Agile / Поэтапный план)

### 2.1. Регламент итераций разработки
* **Длительность этапа (итерации):** 2 недели (10 рабочих дней).
* **События этапа:**
  * *Планирование этапа:* формирование списка приоритетных доработок на ближайшие 2 недели.
  * *Ежедневная координация:* 15-минутная сверка статуса текущих задач.
  * *Демонстрация результатов:* приемка готового функционала заказчиком и техническим руководителем.
  * *Ретроспектива:* анализ качества реализации и оптимизация рабочего процесса.
* **Критерии готовности задачи к разработке:**
  1. Четкая формулировка производственной ценности для заказчика или посетителя сайта.
  2. Подробные критерии приемки результата.
  3. Оценка трудоемкости в относительных единицах сложности.
  4. Отсутствие блокирующих внешних ограничений.
* **Критерии завершения задачи:**
  1. Исходный код написан на TypeScript, отсутствуют замечания системы статического анализа (`npm run lint`).
  2. Сборка производственной версии выполняется без ошибок (`npm run build`).
  3. Проверено корректное отображение на всех типах устройств (компьютеры, планшеты, смартфоны).
  4. Обновлены поисковые метаданные и заголовки страниц.
  5. Функционал протестирован и принят ответственным руководителем.

---

### 2.2. Карта функциональных блоков и требований

#### Блок 1: Каталог оборудования и флагманских комплексов
* **Флагманский комплекс Hexagon:** размещение на главной странице и в каталоге оборудования флагманской связки *Hexagon Absolute Arm + Absolute Scanner AS1 + PolyWorks|Inspector™* с подробными техническими характеристиками для оценки возможностей 3D-контроля геометрии без матирующего спрея.
* **Модульный сканер AS1:** отображение возможности как совместной работы с рукой Absolute Arm, так и полностью автономного использования сканера без КИМ (с оптическим трекером Leica AT960 в радиусе до 30 метров или на роботизированных ячейках).
* **Фильтрация и быстрый подбор:** строгий фасетный фильтр параметров (Точность/Погрешность до 0,01 мм / 0,01-0,05 мм / от 0,05 мм, Форм-фактор: стационарные / портативные, реестр СИ ФГИС «АРШИН») и производители (Hexagon, PMT, Leica, Shining 3D).
* **Интерактивное сравнение и диаграмма параметров (Recharts):** сопоставление до 3 приборов в `CompareDrawer`, визуальный лепестковый радар (RadarChart) метрологического профиля (погрешность, скорость, разрешение, диапазон, мобильность) и столбчатая гистограмма (BarChart) физических величин ГОСТ с инженерным вердиктом.
* **Полнотекстовый поиск по товарам и услугам в Header (`HeaderSearch.tsx`):** интеллектуальная строка поиска в шапке сайта с выпадающим списком результатов прямо под вводом, токенизированным алгоритмом ранжирования по характеристикам, брендам, ценам и услугам, быстрыми фильтрами разделов, клавиатурной навигацией (↑/↓/Enter/Esc) и поддержкой Ctrl+K.

#### Блок 2: Интерактивный модуль расчета и оформление заявок
* **Расчет стоимости услуг:** выбор типа оборудования (3-осевой, 5-осевой или токарно-фрезерный станок с ЧПУ Fanuc, Siemens, Heidenhain, Haas) или параметров детали для 3D-сканирования с мгновенным формированием ориентировочной сметы и коммерческого предложения.

#### Блок 3: Личный кабинет заказчика
* **Служба технической поддержки:** возможность подачи и отслеживания обращений в инженерную службу с фиксацией марки станка, версии программного обеспечения и прикреплением диагностических данных.
* **База знаний и файлы обновлений:** оперативное скачивание проверенных постпроцессоров, шаблонов протоколов измерений PolyWorks и регламентов калибровки.

#### Блок 4: Встроенное управление контентом и статистика посещений
* **Управление разделами:** визуальное редактирование прейскуранта, каталогов, описаний услуг и контактных данных без изменения программного кода.
* **Внутренняя статистика интереса:** встроенный автономный подсчет просмотров страниц и продуктов с формированием сводки популярности решений.

## 3. План реализации этапов проекта

```
[Этап 1: Базовая платформа и каталог] ──> [Этап 2: Инженерные услуги и расчет] ──> [Этап 3: Кабинет заказчика и управление]
  - Каталог ПО TopSolid 7 и PolyWorks           - Модуль расчета стоимости ЧПУ/КИМ            - Личный кабинет и заявки в техподдержку
  - Каталог Hexagon AS1 / Absolute Arm / PMT    - Формирование коммерческих предложений       - Внутренняя статистика посещений
  - Адаптивный интерфейс и поисковая оптимизация - Интерактивный инженерный консультант        - Панель управления и резервные копии
```

### Детализация этапов:
1. **Этап 1: Архитектурная основа и каталог решений**
   - Настройка интерфейса, навигации и структуры компонентов.
   - Описание типизированных структур данных каталога.
   - Страницы каталога ПО (TopSolid, PolyWorks) и измерительного оборудования (Hexagon Absolute Arm, AS1, PMT Alpha).
   - Настройка поисковых описаний и мета-тегов.
2. **Этап 2: Инженерные услуги и прием обращений**
   - Строгое разделение 4 производственных векторов: 3D-сканирование отдельно, реверс-инжиниринг отдельно, контроль на КИМ отдельно, постпроцессоры ЧПУ отдельно.
   - Интерактивный 3D-просмотрщик контроля GD&T (Three.js WebGL) с переключением CAD-моделей, сеток сканирования и карт отклонений.
   - Интерактивный калькулятор трудоемкости с возможностью отправки заявки инженерам.
   - Формы обратной связи и прямой связи с ведущими инженерами.
3. **Этап 3: Личный кабинет заказчика и панель управления**
   - Раздел заказчика: учет договоров, подача заявок в сервисную службу, хранение лицензий.
   - Панель управления сайтом: редактирование статей, оборудования и реквизитов.
   - Инструмент резервного копирования и восстановления данных сайта в формате JSON.
4. **Этап 4: Оптимизация и повышение эффективности**
   - Инструмент автономного сбора статистики просмотров ключевых продуктов.
   - Сводные отчеты по наиболее востребованным решениям.
   - Проверка и полировка удобства пользовательских путей на всех типах устройств.

## 4. Архитектура и программный стек

* **Пользовательский интерфейс (Frontend):** 
  - React 18, TypeScript, Tailwind CSS, Vite.
  - **Высокопроизводительная архитектура (Code Splitting):** разделение бандла через `React.lazy()` — мгновенный старт портала (~120–150 KB gzip), изолированные чанки для CRM, CMS, ЛК и тяжелых библиотек.
  - Векторная библиотека пиктограмм `lucide-react`.
  - **3D WebGL / CAD-рендеринг:** Three.js (просмотрщик деталей, сетки сканов, облака точек и цветовой карты отклонений GD&T) с отложенной загрузкой исключительно при открытии 3D-модуля.
  - **Экспорт/Импорт Excel:** библиотека `xlsx` подключается динамически по требованию (`dynamic import`), не утяжеляя основной бандл.
  - **Графики и визуализация:** Recharts, d3.
* **Серверная часть (Backend & API):**
  - Node.js (Express), `tsx` (разработка), `esbuild` (продакшен бандл CJS).
  - REST API для управления заявками, CRM-сделками, задачами, коммерческими предложениями, договорами и лицензиями.
  - Безопасность: защита от CSRF (Crypto Hex Synchronizer Token Pattern), строгая валидация входящих данных по JSON Schema Draft-07 (Ajv v8).
  - Почтовый шлюз: Яндекс 360 (SMTP/IMAP) с интерактивным редактором HTML-бланков.
* **База данных и персистентность:**
  - **СУБД:** **PostgreSQL 17** (официальный образ `postgres:17-alpine` в Docker Compose).
  - **ORM:** Drizzle ORM (`drizzle-orm/node-postgres`) с пулом соединений `pg`.
  - **Таблица текстовых констант (`text_constants`) и глобальная подгрузка:** специализированная реляционная таблица PostgreSQL, REST API (`/api/text-constants`), сквозная загрузка при старте `AppProvider` и реактивный хелпер `getText()` для всех страниц и компонентов.
  - **Отказоустойчивость:** гибридный режим автоматического переключения на In-Memory и персистентное сохранение состояния в `data/` при временном отсутствии сетевого подключения к СУБД.
  - **Инструмент управления:** встроенный визуальный интерфейс Drizzle Studio (`npm run db:studio`).
* **Модули платформы:**
  - **Полноэкранная рабочая среда CRM (`CrmPage.tsx`):** Выделенный рабочий пульт для менеджеров и инженеров. 10 специализированных разделов: Канбан-воронка (3 воронки сделок), база контрагентов и ЛПР, реестр коммерческих предложений (ТКП и альтернативные КП), задачи и календарь выездов, договоры поставки, график поверок ФГИС «АРШИН», контакт-центр (живой чат «Онлайн-инженер» и обратные звонки), сводный дашборд руководителя, сквозная аналитика и центр настроек. Полная свобода от боковых панелей для максимальной ширины мониторов.
  - **Визуальный Редактор Свидетельств («ДС-Инжиниринг», `CertificateVisualEditorModal.tsx`):** WYSIWYG-конструктор бланков обучения КИМ и САПР, выбор файлов печатей и логотипов с диска, подложки оборудования с регулятором прозрачности, строгое закрепление права подписи только за Генеральным директором (Некрасов С.Ю.) с должностями из реестра сотрудников (`STAFF_DIRECTORY`), полная верстка всех текстовых блоков, 8 прикладных тем обучения, изолированная печать и экспорт в PDF/HTML/PNG.
  - **Парк оборудования и учет средств измерений (СИ):** реестр физических приборов компании (КИМ типа «рука», оптические/лазерные сканеры, трекеры), заводские/инвентарные номера, статусы нахождения, поверки ФГИС «АРШИН».
  - **Реестр метрологических отчетов:** сквозная интеграция с парком приборов, автозаполнение реквизитов СИ, валидация сроков поверки и экспорт протоколов в Excel.
  - **Метрологический конфигуратор оборудования СИ и 3D-визуализатор (`MetrologyEquipmentConfigurator.tsx` + `PartVisualizer3D.tsx`):** Экспертный 4-шаговый подбор измерительного оборудования (стационарные КИМ PMT, оптические/лазерные 3D-сканеры Shining 3D, лазерные трекеры Leica, портативные руки) с расчетом запаса точности $T/\text{MPE}$ (ГОСТ Р ИСО 1101 / ISO 10360), квалитетов IT5–IT12, технологических регламентов и синхронным 3D Solid CAD рендерингом Three.js.
  - **Интерактивный B2B-калькулятор окупаемости внедрения СИ (ROI Calculator, `RoiCalculator.tsx` + `MetrologyRoiCalculator.tsx`):** Финансово-экономическое моделирование окупаемости измерительных комплексов: высвобождение ФОТ контролеров ОТК, сокращение брака детали, расчет срока окупаемости CAPEX и автоматическое формирование официального ТЭО для руководства предприятия.

## 5. Управление проектными рисками

| Производственный риск | Вероятность / Влияние | Меры по предупреждению и устранению |
| :--- | :--- | :--- |
| **Смена модельного ряда оборудования** (например, переход с модели RS6 на сканер AS1) | Средняя / Высокая | Все технические параметры и связки вынесены в модули данных и панель управления CMS, что позволяет мгновенно обновлять номенклатуру без переработки программного кода. |
| **Перебои со связью с внешней базой данных** | Низкая / Высокая | Серверная архитектура оснащена гибридным режимом отказоустойчивости: при недоступности PostgreSQL запросы обрабатываются локально с записью данных в `data/` и последующей синхронизацией. |
| **Сетевые сбои или блокировка трекеров песочницами** | Низкая / Средняя | Клиентский слой `fetchWithCsrf` оснащен синтетическим fallback (503-Response), внешняя аналитика изолирована для Production, rate limiter POST-запросов расширен до 120 req/min. |
| **Очистка данных браузера пользователем** | Низкая / Низкая | Все критические данные синхронизируются с сервером и базой данных PostgreSQL 17, а также доступен экспорт резервных копий сайта и CRM в JSON/XLSX. |
| **Специфика точного расчета сложных деталей** | Средняя / Низкая | В расчетном модуле явно зафиксировано, что полученная оценка является предварительной и уточняется ведущим инженером после анализа 3D-модели детали и кинематики станка. |

## 6. Запуск и эксплуатация

```bash
# 1. Установка библиотек и зависимостей
npm install

# 2. Подготовка переменных окружения
cp .env.example .env

# 3. Запуск базы данных PostgreSQL 17 в Docker
docker-compose up -d postgres

# 4. Применение схемы данных к PostgreSQL (Drizzle ORM)
npm run db:push

# 5. (Опционально) Запуск графической панели управления БД
npm run db:studio

# 6. Запуск сервера разработки (Node.js Express + Vite на порту 3000)
npm run dev

# 7. Проверка качества кода и типизации
npm run lint

# 8. Сборка производственной версии (Vite + esbuild)
npm run build
```
